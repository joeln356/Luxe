### ✂️ Sobre o LEXU

O **LEXU Barber Shop** é um site moderno para barbearias, desenvolvido com foco em design elegante, performance e experiência do usuário.

O projeto simula uma barbearia profissional, com uma interface envolvente, animações suaves e navegação intuitiva — ideal para atrair clientes e destacar serviços.
